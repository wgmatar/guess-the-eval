## Position data

`public/positions.json` is generated by `tools/fetch_positions.py` from **Lichess broadcast
games** (https://lichess.org/broadcast), fetched through the public Lichess API; the
tournaments are listed in `tools/broadcast_tours.json`. Each row is a position from a classical
game between players rated 2500+, with the evaluation Lichess's server-side Stockfish analysis
attached to that move (`[%eval]`), and the players, ratings, event, year and Lichess opening
name from the PGN headers. Lichess publishes its data under CC0; game scores and player facts
are not subject to copyright. Every position links back to its game on Lichess.

## Code dependencies

The built site bundles **React** and **React DOM** (MIT License, Copyright (c) Meta Platforms,
Inc. and affiliates). Everything else in `package.json` is a development tool and does not ship.

The dataset generator uses **python-chess** (GPL-3.0) to parse PGN. It runs offline on a
developer machine only; nothing derived from its code ships in the site.
