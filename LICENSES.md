## Chess piece artwork

The piece shapes in `src/ui/pieces.ts` are the SVG chess pieces by **Colin M.L. Burnett**
("Cburnett"), published on Wikimedia Commons and multi-licensed under **BSD 3-Clause**, GPL,
GFDL and CC-BY-SA-3.0. They are used here under the BSD 3-Clause option, which carries no
copyleft obligation.

`tools/fetch_pieces.py` takes the SVGs from `lichess-org/lila` (`public/piece/cburnett`), whose
path data is identical to the Wikimedia originals. Only the colour tokens are substituted; the
shapes are unchanged. Each black piece also has a rim variant that repeats the same shapes in
ivory beneath the piece, for black pieces on dark squares.

## Position data

`public/positions.json` is generated by `tools/fetch_positions.py` from three sources. Game
scores and player facts are not subject to copyright.

- **Lichess broadcast games** (https://lichess.org/broadcast), fetched through the public
  Lichess API; the tournaments are listed in `tools/broadcast_tours.json`. Each of these rows
  carries the evaluation Lichess's server-side Stockfish analysis attached to that move
  (`[%eval]`). Lichess publishes its data under CC0. These positions link back to their game
  on Lichess.
- **The Lichess masters database** (https://lichess.org/analysis, Masters tab), for elite
  classical tournaments from 2000 to 2019, which Lichess broadcasts do not reach. Game ids come
  from the masters opening explorer API and the PGNs from the Lichess game export API
  (`tools/masters.py`). These games carry no evaluations, so each position was evaluated
  offline with Stockfish (below). They link to the game's page on lichess.org.
- **PGN Mentor's event files** (https://www.pgnmentor.com/files.html), which the site offers
  "completely free", for the same tournaments (`tools/pgnmentor.py`). A game that is also in
  the masters database keeps its masters copy. These games have no page on Lichess, so their
  positions open the Lichess analysis board at that position instead. They were evaluated with
  Stockfish like the masters games.

Each row also keeps the players, ratings, event, year and opening name from the PGN headers.

## Code dependencies

The built site bundles **React** and **React DOM** (MIT License, Copyright (c) Meta Platforms,
Inc. and affiliates). Everything else in `package.json` is a development tool and does not ship.

The dataset generator uses **python-chess** (GPL-3.0) to parse PGN. It runs offline on a
developer machine only; nothing derived from its code ships in the site.

The evaluations of the masters-database and PGN Mentor positions were computed with
**Stockfish 19**
(GPL-3.0, https://stockfishchess.org), one thread and a fixed node budget per position, driven
by `tools/engine.py`. Stockfish runs offline on a developer machine only; the site ships its
numbers, not its code.
